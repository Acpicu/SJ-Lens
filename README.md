# SJ Lens

[![release](https://img.shields.io/badge/release-v1.0.0-22D3EE)](https://github.com/RadarPika/SJ-Lens/releases)
[![license](https://img.shields.io/badge/license-MIT-3B9EFF)](LICENSE)

一个单机版的「关注动态聚合」工具：把你在 B站 / 抖音 / 快手 关注的博主收进一个地方，
不用在几个 App 之间来回翻，点开就知道谁更新了。

- **数据全部存在本机**，不上传任何服务器，没有账号体系
- 没有广告、没有埋点、没有第三方 SDK
- 安装包 **1.7 MB**，Android 7.0 及以上

---

## 能做什么

| 平台 | 作品列表 | 更新检测 | 说明 |
|---|---|---|---|
| **B站** | ⚠️ 最近 30 条（接口第一页） | ✅ 后台自动 + 通知 | 走 B站 公开接口，**需要登录** |
| **抖音** | ⚠️ 首屏预览 | ✅ 按作品总数比对 | 读网页渲染结果，不碰接口签名 |
| **快手** | ⚠️ 首屏预览 | ✅ 按作品总数比对 | 同上，直接打开网页版 |

其他功能：

- **关注夹**：一个人一个卡片，可自定义头像（支持拖动裁切）
- **最近检查**：上一轮检查发现的新内容汇总，带封面，点一下跳去对应 App。
  每轮**整体覆盖**，不需要手动确认或清理
- **检查进度条**：蓝青渐变，两阶段（B站 / 抖音快手）合并计算
- **B站 动态**：投稿和动态分两个页签，纯文字动态用文字卡片展示
- **自动检查**：进应用自动跑一轮 + 每 60 分钟后台跑一次，有新内容发系统通知
- **提醒频率**：给抖音/快手账号单独设「几天提醒我看一次」
- **网页查看**：平台页右上角 🌐 可以直接看到抓取用的那个网页，
  用来判断「页面没渲染」还是「解析失败」
- **导出 / 导入**：全部数据可存成 JSON，换手机时带走

## 已知限制（务必先看）

0. **B站 必须登录才能稳定使用。**
   这是 B站 自己的运维要求，不是本应用的限制：未登录时接口很容易返回 `412 / -352`。
   少数「安全 IP」可能无需登录也能访问，但**如果你第一次访问就被限制，那就是需要登录了**。
   登录入口：`设置 → 账号与登录 → B站`。应用不接触你的密码，登录在官方页面内完成。

1. **更新检测未经完整验证。**
   逻辑是「平台给的计数变大就报更新」，各平台计数口径可能变动，
   **请自行在主页核对数量**。界面里也写明了这一点。

2. **三个平台的作品列表都抓不全。**
   - **B站**：接口按页返回，目前只取第一页，也就是最近 **30 条**
   - **抖音 / 快手**：作品列表是无限懒加载，只能拿到首屏已渲染的封面

   分页/继续加载还没做。**这不影响更新检测** —— 检测看的是总数和快照比对，
   而不是列表里能显示多少条。

3. **抖音 / 快手不能在后台自动检测。**
   读取网页需要真实渲染窗口，后台任务没有窗口。
   所以后台自动检查只覆盖 B站；抖音/快手靠「提醒」兜底。

4. **平台计数可能包含非公开内容。**
   例如「互关好友可见」的草稿箱内容会被算进总数，
   导致显示的条数比公开可见的多 1～2 条。这是平台行为，不是抓取错误。

5. **快手的 `kwai://` 协议唤不起 App**，只能打开网页版。

## 实现要点（踩过的坑）

这些都是实际调试中撞出来的，写在这里省得后来人重走一遍：

1. **平台网页会主动跳 App 深链。**
   抖音主页加载完会立刻跳 `snssdk1128://user/profile?...`，
   WebView 跟着跳就是 `ERR_UNKNOWN_URL_SCHEME`，整个页面被错误页顶掉 ——
   表现是「闪一下主页然后白屏」，而 DOM 里当然什么都抓不到。
   解决：`shouldOverrideUrlLoading` 里只放行 `http(s)`。

2. **WebView 视口不能太小。**
   用 1×1 像素当作「隐藏数据源」会让站点直接渲染成空壳，
   页面 DOM 里没有任何作品节点。必须让它按真实尺寸布局。

3. **不能用 `alpha = 0` 隐藏铺满屏幕的 WebView。**
   `alpha = 0` 的 View **仍然接收触摸事件**，会把整个界面的点击全部吞掉。
   要隐藏又不吃点击，用 `View.INVISIBLE`。

4. **B站 接口需要 WBI 签名 + 设备指纹。**
   缺 `buvid3` 返回 `412`，缺 `dm_img_*` 四个参数返回 `-352`，
   并且必须先访问一次网页把 Cookie 暖起来。

5. **B站 未登录极易被拦。** 所以登录是硬性前提，不是可选优化。

6. **抖音的作品 ID 不在 DOM 里。**
   十多万字符的页面里一个 `aweme_id` 都没有，ID 只存在它的 JS 内存中。
   所以身份标识改用**封面图 URL 的文件名主干**，更新判断用**作品总数**。

7. **分享出来的链接可能不是网页链接。**
   抖音「复制链接」有时给的是 `snssdk1128://` 深链，WebView 根本打不开。
   `PlatformUrls` 会尝试从深链里抠 `sec_uid` 还原成网页地址。

## 构建

需要 JDK 17 与 Android SDK（compileSdk 36）。

```bash
# 调试包
./gradlew assembleDebug

# 正式包（需先准备 keystore.properties）
./gradlew assembleRelease
```

### 签名配置

在项目根目录新建 `keystore.properties`（**不要提交到仓库**）：

```properties
storeFile=keystore/your-release.jks
storePassword=你的密码
keyAlias=你的别名
keyPassword=你的密码
```

生成 keystore：

```bash
keytool -genkeypair -v -keystore keystore/your-release.jks \
  -alias youralias -keyalg RSA -keysize 2048 -validity 10000
```

**没有这个文件也能构建** —— 会自动退回 debug 签名，只是不能发布。

> ⚠️ keystore 和密码一旦丢失，就无法给已安装的用户推送升级，请务必备份。

## 项目结构

```
app/src/main/java/com/sj/followclip/
├── data/
│   ├── local/        持久化（JSON 文件、快照、待确认池）
│   ├── source/bili/  B站接口：WBI 签名、Cookie、检查逻辑
│   ├── source/web/   抖音/快手：隐藏 WebView 抓取
│   └── work/         WorkManager 定时任务
├── domain/model/     数据模型
├── ui/               Compose 界面
└── util/             通知、Cookie、头像存储
```

技术栈：Kotlin + Jetpack Compose + Material 3，**零第三方网络/图片/数据库库**
（HTTP 用 `HttpURLConnection`，JSON 用 `org.json`，图片缓存自己写的 `LruCache`）。
