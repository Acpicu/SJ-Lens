# SJ Lens

一个单机版的「关注动态聚合」工具：把你在 B站 / 抖音 / 快手 关注的博主收进一个地方，
不用在几个 App 之间来回翻，点开就知道谁更新了。

- **数据全部存在本机**，不上传任何服务器，没有账号体系。
- 没有广告、没有埋点、没有第三方 SDK。
- 安装包 1.7 MB 左右。

---

## 能做什么

| 平台 | 作品列表 | 更新检测 | 说明 |
|---|---|---|---|
| **B站** | ⚠️ 最近 30 条（接口第一页） | ✅ 后台自动 + 通知 | 走 B站 公开接口，可登录提升稳定性 |
| **抖音** | ⚠️ 首屏预览 | ✅ 按作品总数比对 | 读网页渲染结果，不碰接口签名 |
| **快手** | ⚠️ 首屏预览 | ✅ 按作品总数比对 | 同上，直接打开网页版 |

其他功能：

- **关注夹**：一个人一个卡片，可自定义头像（支持拖动裁切）
- **待确认**：检查到的新内容汇总在这里，带封面，点一下跳去对应 App
- **B站 动态**：投稿和动态分两个页签，纯文字动态用文字卡片展示
- **自动检查**：每 60 分钟后台跑一次，有新内容发系统通知
- **提醒频率**：给抖音/快手账号单独设「几天提醒我看一次」
- **导出 / 导入**：全部数据可存成 JSON，换手机时带走

## 已知限制（务必先看）

1. **更新检测未经完整验证。**
   逻辑是「平台给的计数变大就报更新」，各平台计数口径可能变动，
   **请自行在主页核对数量**。界面里也写明了这一点。

2. **三个平台的作品列表都抓不全。**
   - **B站**：接口按页返回，目前只取第一页，也就是最近 **30 条**
   - **抖音 / 快手**：作品列表是无限懒加载，只能拿到首屏已渲染的封面

   分页/继续加载还没做。**这不影响更新检测** —— 检测看的是总数和快照比对，
   而不是列表里能显示多少条。

3. **抖音 / 快手不能在后台自动检测。**
   读取网页需要真实渲染窗口，后台任务没有窗口。
   所以后台自动检查只覆盖 B站；抖音/快手靠「提醒」兜底。

4. **平台计数可能包含非公开内容。**
   例如「互关好友可见」的草稿箱内容会被算进总数，
   导致显示的条数比公开可见的多 1～2 条。这是平台行为，不是抓取错误。

5. **快手的 `kwai://` 协议唤不起 App**，只能打开网页版。

## 构建

需要 JDK 17 与 Android SDK（compileSdk 36）。

```bash
# 调试包
./gradlew assembleDebug

# 正式包（需先准备 keystore.properties）
./gradlew assembleRelease
```

### 签名配置

在项目根目录新建 `keystore.properties`（**不要提交到仓库**）：

```properties
storeFile=keystore/your-release.jks
storePassword=你的密码
keyAlias=你的别名
keyPassword=你的密码
```

生成 keystore：

```bash
keytool -genkeypair -v -keystore keystore/your-release.jks \
  -alias youralias -keyalg RSA -keysize 2048 -validity 10000
```

**没有这个文件也能构建** —— 会自动退回 debug 签名，只是不能发布。

> ⚠️ keystore 和密码一旦丢失，就无法给已安装的用户推送升级，请务必备份。

## 项目结构

```
app/src/main/java/com/sj/followclip/
├── data/
│   ├── local/        持久化（JSON 文件、快照、待确认池）
│   ├── source/bili/  B站接口：WBI 签名、Cookie、检查逻辑
│   ├── source/web/   抖音/快手：隐藏 WebView 抓取
│   └── work/         WorkManager 定时任务
├── domain/model/     数据模型
├── ui/               Compose 界面
└── util/             通知、Cookie、头像存储
```

技术栈：Kotlin + Jetpack Compose + Material 3，**零第三方网络/图片/数据库库**
（HTTP 用 `HttpURLConnection`，JSON 用 `org.json`，图片缓存自己写的 `LruCache`）。

## 隐私

- 不收集任何数据，不联网上传任何内容。
- 平台登录在你手机上的 WebView 内完成，**本应用不接触账号密码**，只保留登录后的 Cookie。
- 卸载即彻底清除。
