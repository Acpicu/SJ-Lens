# SJ Lens — OSINT / 数据本模块

> v2.1.0 起，本模块的定位从「自身曝光面自审」改为「目标情报收档」。
> 架构约定不变：单机、零第三方依赖、纯 Kotlin、深色 UI。

## 0. 边界（一次写清，后续不再重复）

| 做 | 不做 |
|---|---|
| 公开页面/公开接口的内容聚合与更新检测 | 抓取私域数据（私信、好友列表、非公开内容） |
| 手工登记公开可见线索，结构化留出处与评级 | 人脸比对、照片地理定位、Exif 反查 |
| 跨平台「可被认定为同一人」的把握度打分 | 手机号/身份证反查、社工库查询 |
| 记录之间的冲突与覆盖缺口的显性提示 | 自动替人下结论、自动判真伪 |
| 按证据强度导出交档简报 | 绕过登录/风控扩容抓取 |

## 1. 模块划分

```
data/osint/
├── ExposureAudit.kt        跨平台关联度打分 + 关联图边（纯函数）
└── PublicContentStats.kt   发布间隔 / 星期分布 / 时段分布 / 数据完整度（纯函数）

data/local/
├── LedgerStore.kt          数据本：记录模型、评级、冲突/缺口、Markdown 报告、旧数据迁移
└── JsonStore.kt            备份：目标 + 账号 + 数据本一体编解码

ui/ledger/
├── LedgerScreen.kt         单目标数据本：登记、筛选、改、状态流转
├── LedgerOverviewScreen.kt 全部目标：跨目标搜索 + 汇总
├── LedgerReportScreen.kt   报告预览（与导出的 .md 同内容）
└── LedgerParts.kt          三屏共用的记录卡、状态色、单选 chip 行
```

依赖方向：`ui → data/local | data/osint → domain/model`。引擎层不 import android.*，可在 JVM 单测里直接跑。

## 2. 一条记录的结构

| 字段 | 说明 |
|---|---|
| `id` | `L-001` 起，只增不改，删号不复用 |
| `kind` | 账号 / 身份 / 联系 / 单位 / 地点 / 时间 / 关系 / 内容 / 行为 / 其他 |
| `fieldName` | 字段名，如「手机号」「B站 UID」。**不能叫 field**：会撞 getter 里的 `field` 关键字 |
| `value` | 原样保存，不做清洗、不做归一 |
| `sourceUrl` | 出处原话：URL / 页面标题 / 文件名 |
| `grade` | Admiralty `A–F` + `1–6`，非法值一律置空，不猜 |
| `confidence` | 低 / 中 / 高，与「状态」分开：状态是结论，置信度是对这条的把握 |
| `status` | 待验证 / 已证实 / 已推翻 |
| `tags` / `note` / `shotPath` | 标签、备注、截图绝对路径 |

## 3. 分析口径

- **冲突**：`status != 已推翻` 的记录里，同名字段（忽略大小写与首尾空白）出现 ≥2 个不同值。
  只点名，不裁决。
- **缺口**：六类关键事实（真实身份 / 联系方式 / 单位 / 城市 / 作息 / 关系人）没有任何记录时列出。
- **关联度**：昵称相同 30、包含 18、差一字 12；同一头像 25、近似（汉明 ≤8）15；
  简介共用词每对 8（上限 16）；可被搜到 10。总分 ≥25 中风险，≥60 高风险。

## 5. 顺带查出的既有问题

- v1 时代 `HomeScreen.kt` 混入过 GBK 字节的注释行，编译能过但文本乱码；v2.1.0 已统一为 UTF-8，
  后续禁止用 GBK 编辑器局部粘贴。
- 交接报告曾以明文写入 release keystore 的路径、alias 与密码。若该文档流出过，
  应视为密钥泄露：换 keystore + `versionCode` 继续递增。与本次改动无关，单独处理。
