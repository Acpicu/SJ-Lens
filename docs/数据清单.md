# 数据清单：SJ Lens 到底记录了什么

> 回答一个问题：这个应用在你手机上留下了哪些东西、每条字段是什么、存在哪、怎么删。
> 结论先给：**全部在本机，没有任何一条上传。**

---

## 一、落盘的东西（7 类）

### 1. 文件夹与账号（主数据）

存储：应用私有目录下的 JSON 文件（`filesDir`，由 `JsonStore` 读写）

| 字段 | 含义 |
|---|---|
| `Person.id` | 文件夹 ID |
| `Person.remarkName` | **你自己起的备注名**（不是你抓到的平台昵称） |
| `Person.avatarUrl` | 头像地址（若来自平台） |
| `Account.id` | 账号 ID（同平台多号靠它区分） |
| `Account.platform` | BILI / DOUYIN / KUAISHOU |
| `Account.homepageUrl` | 你填的主页链接或 UID |
| `Account.label` | 别名（如「生活号」） |
| `Account.unreadCount` | 上次比对出的新作品数 |
| `Account.lastFetchAt` | 上次抓取时间 |
| `Account.followerCount` / `videoCount` | 粉丝数 / 作品数（抓到时才有） |
| `Account.remindEveryDays` / `lastRemindAt` | 提醒周期与上次提醒时间 |

### 2. 抓取快照（判断"有没有更新"的依据）

存储：SharedPreferences `video_snapshots`
内容：每个账号最近 **60 条**作品的 ID 列表；动态另存一份（键带 `dyn` 后缀）
用途：新一轮抓取跟上次比对，算出新增；首次只建基线不报"新"

### 3. 最近检查结果

存储：SharedPreferences（`PendingStore`）
内容：上一轮检查每个文件夹的命中条目
特性：**每轮整体覆盖**，只留最近一次

### 4. 笔记

存储：SharedPreferences `sj_notes`
键：`note_<personId>` 文本 + `note_at_<personId>` 更新时间
内容：你自己写的自由文本（判断、观察、结论草稿）

### 5. 证据与待验证清单

存储：SharedPreferences `sj_evidence`

| 键 | 内容 |
|---|---|
| `ev_<personId>` | JSON 数组，每条：`id`(E-001) / `source` / `at` / `sha` / `grade` / `note` / `photo` |
| `seq_<personId>` | 证据编号计数器（只增，删除不复用） |
| `todo_<personId>` | JSON 数组，每条：`id`(T-01) / `text` / `check` / `status`(0 未验证 1 已证实 2 已推翻) |
| `todo_seq_<personId>` | 待验证编号计数器 |

### 6. 截图文件

存储：`filesDir/evidence/<personId>/shot_<时间戳>.jpg`
来源：你在证据条目里点「附截图」选中的图，复制一份进私有目录
附带：登记时自动算 SHA-256 写进证据

### 7. 头像与登录态

- **文件夹头像**：`AvatarStore` 存的 256×256 裁切图（你自己拖拽裁的）
- **B站登录态**：只保留 `SESSDATA` 等 Cookie（不接触密码）
- **首次运行标记**：SharedPreferences `first_run`（弹窗只弹一次）

---

## 二、不落盘的东西

| 内容 | 说明 |
|---|---|
| 视频文件 / 图片（除头像与证据截图） | 列表只存 URL，不缓存在本地 |
| 页面原始 HTML | 抖音/快手用隐藏 WebView 当场读 DOM，抓完即走（代码里没有页面缓存逻辑） |
| 你的浏览行为 | 没有埋点、没有崩溃上报、没有广告 SDK、没有统计 SDK |
| 通讯录 / 短信 / 定位 / 相机 | 未申请这些权限 |

**权限只有两个**：`INTERNET`、`POST_NOTIFICATIONS`。

---

## 三、删除方式

| 数据 | 怎么删 |
|---|---|
| 文件夹 / 账号 / 快照 / 最近检查 / **笔记 / 证据 / 待验证 / 截图目录** | 设置 → 数据 →「清除全部本地数据」（现已连带清理） |
| 单条证据 | 证据页 → 该条「删除」 |
| 单个待验证项 | 证据页 → 该条「删除」 |
| 单个文件笔记 | 文件夹内「笔记」→「清空」 |
| B站登录态 | 设置 → B站「退出」 |
| 全部（含首次运行标记） | 系统设置 → 应用 → SJ Lens → 清除数据 / 卸载 |

---

## 四、导出会产生什么

| 动作 | 产出 | 里面有什么 |
|---|---|---|
| 设置 → 导出数据 | `.json` | **只有文件夹与账号**（笔记、证据不在里面） |
| 证据页 → 导出 | `.md` | 结论 / 证据（含 SHA-256 与截图**文件名**）/ 置信度占位 / 待验证清单 |
| 证据页 → 预览 | 无文件 | 应用内阅读，截图原图就地显示 |
| 曝光审计 → 复制报告 | 剪贴板 | 关联度分数 + 命中因子 + 收敛建议（**不含**你填的昵称原文以外的信息） |

⚠️ 导出的 `.md` 和 `.json` 一旦发出去就不受本应用控制了，发之前自己过一遍。
